# Multi-Cloud Asset Cost Optimization Portal

## Project Overview

The Multi-Cloud Asset Cost Optimization Portal is a FinOps analytics system designed to help organizations monitor and optimize cloud infrastructure costs across AWS, Microsoft Azure, and Google Cloud Platform (GCP).

The system analyzes cloud billing data, identifies unused or inefficient cloud resources, provides cost insights, and helps organizations detect budget breaches and optimize cloud spending.

## Problem Statement

Organizations using multiple cloud platforms often face difficulties in tracking cloud costs, identifying idle resources, and monitoring budget usage.

This project provides a centralized portal that can:

- Ingest cloud billing CSV files from AWS, Azure, and GCP
- Normalize and categorize cloud cost information
- Analyze departmental and project-wise cloud spending
- Identify idle compute instances
- Detect unattached storage volumes and unused resources
- Estimate potential cost savings
- Monitor budget thresholds and forecast anomalies
- Send budget breach notifications

## Target Users

The main stakeholders of the system are:

- **FinOps Analyst** – Monitors cloud expenditure, analyzes costs, and identifies optimization opportunities.
- **Cloud Administrator** – Manages cloud resources and takes action on inefficient or unused resources.
